# AITTS V5 — Organic Chemistry Intelligence UI

This version positions AITTS as an Organic Chemistry-only testing and performance-intelligence platform.

## What's new
- Organic Chemistry-only product positioning across the landing page.
- Intelligence-first hero: Organic Chemistry DNA, detected patterns and next move.
- Organic War Room section for preparation intelligence.
- Error-fingerprint / concept-intelligence / decision-analytics feature language.
- Marketplace with the three supplied M.S. Chouhan book covers and Amazon destinations.
- Connect Here section with official YouTube and Instagram destinations supplied by the user.
- Student dashboard upgraded with an Organic Intelligence banner while preserving existing API-driven data.
- Existing Neon/PostgreSQL, auth and API routes are retained.

## Run
Copy the working `.env.local` from your existing AITTS project into this project root, then:

```bash
npm install
npm run build
npm run dev
```

Do not commit `.env.local`.
